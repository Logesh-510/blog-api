# Blog Notification Center — React Frontend

A responsive React + Vite frontend for the **Blog Management API Notification Center**.

This application provides a notification bell interface where authenticated users can view, read, unread, and manage notifications generated by the FastAPI backend.

---

## 📌 Project Overview

The **Blog Notification Center** is a frontend application built with React and Vite.

It connects to the FastAPI backend and displays notifications for:

* ❤️ Post likes
* 💬 Post comments
* 💳 Subscription activation
* 🔄 Subscription renewal

The notification center includes an unread notification badge, notification type icons, friendly timestamps, individual read/unread controls, and a **Read All** feature.

The application automatically checks for new notifications every **10 seconds**.

The frontend automatically requests the latest notifications from the backend every **10 seconds**.

## 🔐 Authentication Flow

The frontend uses the backend JWT authentication system.

### Login

The frontend sends the username and password to:

```http
POST /auth/login
```

After successful authentication:

1. The backend returns a JWT access token.
2. The token is stored in browser `localStorage`.
3. The frontend uses the token for authenticated API requests.
4. Notifications are fetched using the JWT token.

Example authorization header:

```http
Authorization: Bearer <access_token>
```

For security, actual JWT tokens are not stored in the source code.

## 🔔 Notification API Integration

The frontend integrates with the following backend endpoints.

### Get Notifications

```http
GET /notifications/
```

Retrieves notifications belonging to the authenticated user.

### Get Unread Count

```http
GET /notifications/unread-count
```

Retrieves the number of unread notifications.

### Mark Notification as Read

```http
PATCH /notifications/{notification_id}/read
```

### Mark Notification as Unread

```http
PATCH /notifications/{notification_id}/unread
```

### Mark All Notifications as Read

```http
PATCH /notifications/read-all
```

## 🔄 Notification Refresh Flow

The frontend performs the following process:

```text
User Login
    ↓
JWT Token Stored
    ↓
Fetch Notifications
    ↓
Display Notification Bell
    ↓
Show Unread Badge
    ↓
Check Backend Every 10 Seconds
    ↓
Update Notification List
```

This allows newly generated notifications to appear automatically without manually refreshing the browser.

## 🔔 Notification Types

The frontend supports the following notification types:

### ❤️ Like

Displayed when another user likes the authenticated user's post.

Example:

```text
comment_test_user liked your post 'Dashboard Test Post'.
```

### 💬 Comment

Displayed when another user comments on the authenticated user's post.

Example:

```text
logesh commented on your post 'Dashboard Test Post'
```

### 💳 Subscription

Displayed when a subscription is activated.

Example:

```text
Your Basic subscription has been activated successfully.
```

### 🔄 Subscription Renewal

Displayed when an existing subscription is renewed.

Example:

```text
Your Basic subscription has been renewed successfully.
```
